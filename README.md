# VietNamFoodRegconizer

Around mid 2025, I built this project as a product for the computer vision competition.
The data I gathered were around 98 different Vietnamese foods/plates, from everyday meal to regional specialty.
The main purpose of this app was to help eatery/restaurant/food stall automate their checking out. The customer only need to scan their tray with their meal on it then the pc will automatically scan and make the bill, then the customer only need to pay with cash or scan RQ code to pay.
